# Movie Magic

A website for discovering movies and TV shows, viewing details,
writing reviews, giving ratings, and saving favorites.

## Core features
- Search movies and TV shows by title.
- Browse by genre and release date.
- Browse trending content, popular shows, and upcoming movies.
- View summaries, cast, crew, TMDb ratings, and trailers.
- Create an account and sign in.
- Rate titles from 1 to 5 stars and write optional reviews.
- Save and manage favorites.

## Optional feature: Scene Finder
Search for a moment using a text description.
Initially, this will search 2–3 selected trailers, not full movies.
It will return a matching timestamp and play that part of the trailer.

## Planned technology
- Frontend: React, JavaScript, HTML, and CSS.
- Backend: Python with FastAPI.
- Movie information: TMDb API.
- Login: Firebase Authentication.
- Saved data: Cloud Firestore.
- Collaboration: GitHub.

## Project folders
- frontend: website interface.
- backend: API routes and TMDb integration.
- docs: project plan and shared data formats.

## Team workflow
1. Pull the latest main branch before starting.
2. Create a branch for your task.
3. Write and test your changes.
4. Commit and push your branch.
5. Open a pull request.
6. Ask a teammate to review before merging.

Every task should have an owner, deadline, and clear deliverable.
Everyone tests their own work and another person's feature.

## Credentials
